# Owned pending Future NativeAOT candidate

`oresnet emit-owned-unwind-v1 input.atto --out Guest.g.cs` emits static C# source from the two identical shared owned Future fixtures. The normal structured parser stays fail-closed. The opt-in lane uses its production lexer and bounded formal-slot parser, one to eight distinct owned Future<int> inputs, braceless deferred await, literal or awaited return, optional single recovery with awaited return. No arbitrary captured callbacks or general MIR. The generated continuation switch is compiled with Roslyn and NativeAOT, not interpreted or runtime-generated. Frame is a 208-byte inline array value; trusted host must not copy live frames and must serialize access. Numeric owner, epoch and error tokens are not authenticated capabilities. Successful and failing guest transitions do not allocate; native probe measures managed allocations only, not runtime initialization or host allocation. Separate READY publication and resume. Retire clears frame, permanently seals it. Existing runtime SelectContinuationFence/SelectableI64Future not connected yet; actor scheduler, STOP deadlines, actual Future claim authority and error identity mapping remain required. Explicit draft scope, independent review and overlap reconciliation needed.

## Trusted NativeAOT runtime probe

The generated guest is now exercised with the existing SelectableI64Future and SelectContinuationFence. The adapter claims exact Future identities transactionally within its own domain; producer callbacks only stage readiness, and a separate trusted Pump claims and resumes the guest. A persistent physical pin spans all awaits and terminal publication, preventing generation advance. STOP requests unsubscribe and synthesize cancellation on pending and remaining cleanup awaits, with already-staged receipts winning. This bounded behavior is not a general STOP policy or deadline; legacy Future consumers do not share the claim domain, arbitrary actor DATA scheduling/nonreentrancy and concurrent external fence Close remain open. Host allocates managed bookkeeping, separate from the zero-allocation generated frame probe. Failed post-admission invariant is fail-stop, not proof of reclamation.
